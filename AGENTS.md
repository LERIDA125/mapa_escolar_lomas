# OpenCode Agent Directives: Mapa Escolar Lomas

1. **Arquitectura Oficial:** Lee SIEMPRE `docs/01_PRD.md` antes de proponer código. El proyecto usa Flutter (Dart) con una base de datos local JSON (Offline-First).
2. **Gestión de Estado:** Usa EXCLUSIVAMENTE Riverpod. Nunca pongas lógica de negocio dentro de los widgets de UI.
3. **Control de Versiones:** Lee `docs/03_Guidelines.md`. Crea siempre ramas `feature/TICK-XXX-nombre` y usa Conventional Commits (`feat:`, `fix:`).
4. **Contexto de UI:** Si pido armar una pantalla, busca las imágenes de referencia en `docs/wireframes/` y usa Material Design 3.
5. **Tracker:** Al finalizar una tarea, proponme actualizar el estado de la tabla en `docs/04_Tickets.md`.
